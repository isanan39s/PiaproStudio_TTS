# PiaproStudio_TTS 配布用readme

Open JTalk と Piapro Studio VSTi (初音ミク V4X 等) を連携させ、形態素およびフルコンテキストラベル（HTS形式）に基づいた高品質な歌声合成（TTS）を行うためのシステムです。

---

## 📌 概要

本システムは、入力されたテキストを日本語解析エンジン **Open JTalk** を用いて音素・アクセント情報に分解し、**LibreSVIP** を通じて VSTi (Piapro Studio) が解釈可能な歌声プロジェクトファイル (`.ppsf`) を自動生成します。
生成されたシークエンスをホストプログラム経由で VSTi に読み込ませ、スピーカー再生および高品位な 16bit WAV ファイルとしてのレンダリング・音声取得を実現します。

---

## 💻 必要な動作環境・前提条件

本ツールを動かすには、ユーザー側の環境に以下の製品がインストールされている必要があります。**これらは本システムに同梱して配布することはできません。**

1. **Piapro Studio VSTi (または VOCALOID4 VSTi)**
   * 通常、`C:\Program Files\Vstplugins\Piapro Studio VSTi.dll` 等にインストールされます。
2. **有効なライセンスで認証された VOCALOID4 ボイスバンク**
   * 例:
      - 初音ミク V4X 
      - piapro characters SUPER PACK など

## APIとポート構成
### 🛠️ API の使い方 (ポート 8080)

起動中、ブラウザや `curl` 等で `http://localhost:8080/` にアクセスすることで制御できます。

#### 1. 音声生成 ＆ WAVデータダウンロード
* **リクエスト**: `GET` または `POST`
* **エンドポイント例 (GET)**:
  `http://localhost:8080/?cmd=getwav&text=こんにちは`
* **レスポンス**: 生成された音声の `audio/wav` バイナリ (16bit PCM, Stereo, 48kHz) が直接返却されます。

#### 2. リアルタイム再生 (WAVなし)
* **エンドポイント例 (GET)**:
  `http://localhost:8080/?cmd=say&text=おはようございます`

### ポート
本システムは、GUI、Goホスト、Python変換サーバー間で以下のポートを使用したローカル通信を行います。

| ポート番号 | 用途 | 通信タイプ | 説明 |
| :--- | :--- | :--- | :--- |
| **8080** | **Go HTTP API サーバー** | 外部 / ローカル受付 | HTTP API 経由で外部のプログラム（LLM等）やローカルリクエストからミクさんらに喋らせるための窓口です。 |
| **8000** | **Python FastAPI サーバー** | 内部通信専用 (`127.0.0.1`) | Go側から受け取った音符・歌詞データを、LibreSVIP を通して `.ppsf` バイナリデータに変換するためのpython用ポートです。 |
